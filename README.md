# CHAT APP PROJECT
Sipmle messenger-like chat app built with NextJS made with websockets. Not deployed yet.

## Technologies Used
- **Main Language**: Typescript
- **Bundler**: NextJS
- **Main front-end framework**: React
- **Database**: Postgresql with Prisma

### To start the server localy

```
npm run dev:socket
```

### Enviremental variables

The application needs a .env file in the root directory in order to work properly.

A template for your .env file (all required):
```
HOSTNAME=
PORT=
JWT_SECRET=

DATABASE_URL=postgresql://postgres:
```
